# 문자열 덧셈 계산기

## 기능 목록

### 1. 문자열 입력 기능
- 사용자에게 입력 안내 문구 출력한다.
- `readLine()`을 사용하여 문자열 입력을 받는다.

### 2. 기본 구분자 처리
- 빈 문자열 입력 시 결과값 0을 반환한다.
- 쉼표(,)를 기준으로 숫자를 분리한다.
- 콜론(:)을 기준으로 숫자를 분리한다.
- 분리된 숫자들을 정수로 변환한다.
- 변환된 숫자들의 합을 계산한다.

### 3. 커스텀 구분자 처리
- 문자열 앞부분의 `"//"`와 `"\n"` 사이에 있는 문자를 커스텀 구분자로 인식한다.
- 커스텀 구분자를 기준으로 숫자를 분리한다.
- 분리된 숫자들을 합산하여 결과를 반환한다.

### 4. 예외 처리
- 입력값이 잘못된 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
  - 음수가 입력된 경우 예외 발생
  - 숫자가 아닌 문자가 구분자 외에 포함된 경우 예외 발생
